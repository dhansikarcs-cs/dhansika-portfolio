03 / 13 CURRENT RESEARCH

RESEARCH QUESTION

What happens when intrusion-detection models encounter data that differs from what they were trained on?

Using CICIDS2017, four models are evaluated across conventional evaluation and multiple distribution-shift scenarios. The paper is currently being completed.

LOGISTIC REGRESSIONRANDOM FORESTXGBOOSTMULTI-LAYER PERCEPTRON
A

Conventional random split

Baseline evaluation under a standard random train/test partition — the setting benchmark performance is normally reported in.

BASELINE
B

Session / attack-family shift

Training and test data drawn from different sessions and attack families — closer to real deployment.

DISTRIBUTION SHIFT
C

Attack-family leave-one-out

Each attack family withheld in turn during training, then used for evaluation — a test of generalization to unseen attacks.

GENERALIZATION
D

Synthetic feature perturbation

Controlled perturbation of synthetic features to probe resilience to feature-level distributional drift.

05 / 13 HOW I ENGINEER

I think in systems.

The discipline underlying everything in this portfolio — how components relate, fail and depend on each other.

SYS-01

Architecture before features

Every component lands inside a relationship diagram before it lands in code — dependencies, interfaces and failure points are designed first.

SYS-02

Workflows are first-class

Systems are judged by whether the workflow they support is honest: intake, processing, handoff, review, delivery.

SYS-03

Testing as evidence

Simulation, security testing and external feedback are treated as evidence about the system — not an afterthought.

SYS-04

Security is structural

Privacy and security are architecture decisions — especially in clinical or personal data systems — not features bolted on later.

SYS-05

Documentation as part of the build

Technical documentation and reproducibility sit inside the engineering loop — a system is not finished if it cannot be explained.

SYS-06

Questioning the finished

A system that runs is not a system that works. What assumptions does it depend on? Where could it fail? What happens when those change?
